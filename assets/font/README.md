# VGA8.F16

The IBM VGA 8×16 character ROM font (256 glyphs × 16 bytes, one bit per pixel),
taken from VileR's collection of VGA text-mode fonts:
<https://github.com/viler-int10h/vga-text-mode-fonts> (`FONTS/PC-IBM/VGA8.F16`).

These are the same glyphs as the *Px437 IBM VGA 8x16* font in
*The Ultimate Oldschool PC Font Pack* by VileR (<https://int10h.org/oldschool-pc-fonts/>),
which is licensed under the Creative Commons Attribution-ShareAlike 4.0
International license (CC BY-SA 4.0).

`tools/assets.py` turns it into the glyph costumes used by the pen text engine.
