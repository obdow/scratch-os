SCRATCHOS(7)               ScratchOS Manual

    ScratchOS is an operating system written for Scratch (TurboWarp).

    * every pixel is drawn with the pen; text is stamped glyph by glyph
      in JetBrains Mono on a 1280x720 (160 x 45 cell) screen
    * one keyboard clone per key listens for input - no ask blocks
    * preemptive multitasking of Whisker bytecode programs
    * in-memory file system rebuilt from the boot image every start
    * Unix-like shell with pipes, redirection and background jobs
    * a desktop: menu bar, a Windows-style taskbar and Start menu, windows,
      Finder, Terminal, the Whisker IDE, light and dark appearance
    * capability-based permissions with interactive prompts
    * Paint, Preview and the .simg picture format (man simg)
    * the Browser, for web pages written in Yarn (man yarn)
    * the ScratchOS network over cloud variables: net://, `net` (man net)

    ScratchOS boots to the desktop.  Hold Esc while it boots for the text
    console; `startx` starts the desktop from there.  On the desktop,
    Ctrl+Space opens the cat menu; `ide FILE` opens a file in the IDE.
