Welcome to ScratchOS!

Everything you see is drawn with the Scratch pen: text is stamped glyph by
glyph from the IBM VGA 8x16 font, and windows are filled rectangles.

Try:
  ls /bin              see the programs (written in Whisker)
  cat /bin/hello.wsk   read one
  hello                run it
  edit notes.txt       write something
  startx               start the desktop
