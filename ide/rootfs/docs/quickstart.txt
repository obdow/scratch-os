WHISKER IDE - QUICK START

  Ctrl+Enter      run the current file        Esc     stop / open the menu bar
  Ctrl+Space      autocomplete                Ctrl+/  comment / uncomment
  Ctrl+Z / Y      undo / redo                 Ctrl+D  duplicate line
  Ctrl+X/C/V      cut / copy / paste          Ctrl+A  select all
  Shift+arrows    select text (or drag with the mouse)
  Ctrl+Home/End   start / end of file         Ctrl+Left/Right  word jump

  The menu bar (click it, or press Esc) has everything else:
  File  New, Save, Save as, Rename, Delete, Close, Export, Import
  Edit  Undo, Redo, Cut, Copy, Paste, Find, Replace, Go to line ...
  Run   Run, Stop, Check syntax, Clear output
  View  File tree, text preview / edit, output panel size, theme
  Help  this page, the language reference, About

  Programs print into the Output panel at the bottom.  When a program
  reads input, type into the Output panel and press Enter.  Programs that
  open a window (gui.window) appear in a preview pane above it.

  Errors are marked with a red line number; click the error in the
  Output header, or use Run > Go to error, to jump there.

  Files live in memory.  To keep your work, use File > Export: the file
  appears in a list on the stage - right-click it and choose "export".
  File > Import does the reverse (right-click the list, "import", then
  choose File > Import again).

  Text files (anything that is not a .wsk program, like these docs) open
  in a formatted Preview with word wrap.  Ctrl+E, or the Preview / Edit
  switch at the right of the tab bar, switches to plain-text editing.

  Libraries in /lib load with require: local sort = require("sort") gives
  a dozen sorting methods (see /docs/sort.txt and /examples/sorting.wsk).

  Start with the files in /examples (double-click them in the tree).
